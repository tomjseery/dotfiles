# Themes

## Ownership
- `shared/` owns cross-desktop appearance; profiles consume it without copying its choices.
- Presets own visuals, not input bindings, app pins, agent settings or credentials.

## Published appearance
- Keep each published preset's README, source credits and screenshots with the preset.
- Refresh affected screenshots when appearance changes; capture real output, not mockups.
- Keep originals and generated wallpaper variants separate; retain prompts and provenance.
