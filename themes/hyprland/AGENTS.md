# Hyprland presets

## Preset folders
- Each preset owns `settings.json`, `scheme.json`, wallpaper assets, `README.md` and `screenshots/`.
- Keep overlays small; reset visual options that could carry over from another preset.
- Leave application icon choice to [shared appearance](../shared/AGENTS.md).

## Switching
- Use the shell's native Presets mechanism.
- Preserve the last selected preset and running terminal sessions.
- Shared controls and rendering logic stay in [the desktop module](../../desktops/hyprland/AGENTS.md).
